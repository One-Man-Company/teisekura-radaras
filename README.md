# Teisėkūros radaras — viešos apžvalgos

Automatiškai generuojamos Lietuvos teisės aktų analizės: kas savaitę paskelbiama
reikšmingiausių priimtų aktų ir projektų apžvalga, kiekvienas aktas turi atskirą
puslapį su pilna analize.

Šaltiniai: TAR (teises aktai), TAIS (projektai), e-pilietis (konsultacijos),
Seimo balsavimai — per `get.data.gov.lt` atviruosius duomenis.

**Analizės generuojamos automatiškai ir nėra teisinė konsultacija.** Kiekvieno
puslapio apačioje nurodytas analizės režimas ir modelis.
